       ```rust
       pub async fn enrich_scan(
           scan: &mut ScanResult,
           nvd: Option<Arc<NvdSource>>,

       Each source is `Option` — `None` means disabled or unavailable.

    6. **Inside each spawned task**, for each CPE:
       a. **Cache check first:** Call `cache::read_cache("nvd", cpe, cache::DEFAULT_TTL_SECS, opts.fresh).await`. If Some(cached_vulns), use them and skip NVD network call. Print `"[{pos}/{total}] NVD (cached): {product}... {n} CVEs"` if not quiet.
       b. **NVD lookup** (if nvd is Some and not cached): Call `with_retry(|| nvd.lookup_cpe(cpe))`. On Ok(vulns), call `cache::write_cache("nvd", cpe, &vulns).await`. Print `"[{pos}/{total}] NVD: {product}... {n} CVEs"`.
       c. **OSV lookup** (if osv is Some): Same pattern — cache check with source="osv", then `with_retry(|| osv.lookup_cpe(cpe))`, cache write. Print `"[{pos}/{total}] OSV: {product}... {n} CVEs"`.
       d. **CVE.org enrichment** (if cve_org is Some): Existing pattern, enrich per-CVE. No cache for CVE.org (it enriches existing CVEs, not a lookup source).
       e. **Dedup all vulns** from NVD + OSV using existing `dedup_vulnerabilities()`.

    7. **SearchSploit step** (after vuln enrichment, if searchsploit is Some):
       For each service with product+version, call `searchsploit.search_product(product, version).await`. Store results in `port.exploits`. Handle ExploitLookupError::Empty as non-error. Print `"[{pos}/{total}] SearchSploit: {product} {version}... {n} exploits"` per D-15.

    8. **Build source_status** at the end per D-16:
       Track which sources succeeded/failed across all services. Add to EnrichmentStats.source_status entries like `("NVD", true)`, `("OSV", false)`.

    9. **Maintain backward compatibility:** All existing behavior preserved. The new sources and cache are additive.

       #[arg(long)]
       pub fresh: bool,

       /// Disable a named source (repeatable): nvd, cveorg, osv, searchsploit
       #[arg(long = "disable-source", value_name = "SOURCE", action = clap::ArgAction::Append)]
       pub disable_sources: Vec<String>,
       ```

    2. **Update src/main.rs run() function:**
       a. After parsing CLI, create sources conditionally:
       ```rust
       let opts = portreaper::enrichment::EnrichmentOptions {
           concurrency: 5,
           quiet: cli.quiet,
           fresh: cli.fresh,
           disabled_sources: cli.disable_sources.iter().map(|s| s.to_lowercase()).collect(),
       };

       let nvd = if opts.source_enabled("nvd") {
           let api_key = std::env::var("PORTREAPER_NVD_KEY").ok();
           Some(Arc::new(portreaper::sources::nvd::NvdSource::new(api_key)))
       } else { None };

       let cve_org = if opts.source_enabled("cveorg") {
           Some(Arc::new(portreaper::sources::cve_org::CveOrgSource::new()))
       } else { None };

       let osv = if opts.source_enabled("osv") {
           Some(Arc::new(portreaper::sources::osv::OsvSource::new()))
       } else { None };

       let searchsploit = if opts.source_enabled("searchsploit") {
           match portreaper::sources::searchsploit::SearchSploitSource::try_new() {
               Some(s) => Some(Arc::new(s)),
               None => {
                   if !cli.quiet {
                       eprintln!("searchsploit not found — skipping exploit lookup");
                   }
                   None
               }
           }
       } else { None };
       ```
       b. Call updated enrich_scan with all optional sources:
       ```rust
       let stats = portreaper::enrichment::enrich_scan(
           &mut result, nvd, cve_org, osv, searchsploit, &opts
       ).await;
       ```
       c. Print source status summary per D-16 after enrichment:
       ```rust
       if !cli.quiet && !stats.source_status.is_empty() {
           let status_line: Vec<String> = stats.source_status.iter()
               .map(|(name, ok)| if *ok { format!("{} OK", name) } else { format!("{} FAIL", name) })
               .collect();
           eprintln!("Sources: {}", status_line.join(", "));
       }
       ```

    3. **Extend vault service note template** in `src/vault/templates.rs`:

       pub fn render_service_body(

       // Exploits section (D-01: separate section below CVEs)
       if !exploits.is_empty() {
